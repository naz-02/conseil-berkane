# Portail Institutionnel - Conseil Provincial de Berkane

The official web portal for the **Conseil Provincial de Berkane**, designed to facilitate communication between the council and citizens, showcase development projects, and provide transparent access to administrative structures.

🔗 **Live Site:** [www.cpberkane.com](https://www.cpberkane.com)

![Conseil Provincial de Berkane](src/assets/logo-ar.png)

## Features

-   **Dynamic Organigram**: Interactive visualization of the administrative and political structure.
-   **News & Activities**: Up-to-date coverage of council meetings, official visits, and partnerships.
-   **Project Portfolio**: Showcase of developmental projects (Infrastructure, Social, Cultural).
-   **Bilingual Support**: Fully localized content in Arabic and French.
-   **Responsive Design**: Optimized for mobile, tablet, and desktop experiences.

## Technology Stack

-   **Frontend Framework**: [Angular 17+](https://angular.io/)
-   **UI Components**: [PrimeNG](https://primeng.org/)
-   **Styling**: Modern CSS3, Flexbox/Grid, Responsive Layouts
-   **Routing**: Angular Router for seamless navigation

## Development

This project was generated with [Angular CLI](https://github.com/angular/angular-cli).

### Prerequisites
-   Node.js (LTS recommended)
-   Angular CLI

### Running Locally
```bash
ng serve
```
Navigate to `http://localhost:4200/`.
